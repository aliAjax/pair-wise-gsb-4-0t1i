# 声线练习室

React + Vite + TypeScript 的发音练习应用。除句子库与录音练习外，提供**离线录音保管账本**与**离线清理台**。

## 录音保管

- 每条录音登记：所属句子、录音日期、体积、保留至（可选 7 / 30 / 90 天），并记录最近复听日期。
- 容量账本展示总容量 / 已用 / 剩余，全部持久化在 `localStorage`。
- 停止录音后进入「待保存」状态：确认后才入账；剩余空间不足时无法入账。

## 清理台规则

剩余空间不足时，只允许清理**同时满足**以下条件的版本：

1. 所属句子已掌握；
2. 七天内没有复听过；
3. 保留至日期已到。

清理预览先锁定候选，出现以下任一情况则**整批阻止**（一条都不会删除，旧录音不丢失）：

- 存在待保存录音；
- 候选范围中存在同一句的最新版本。

冲突会列出句子、日期、体积和具体限制；对最新版本或近期复听的版本执行一次复听，可使其重新进入七天保护后重新锁定。确认后容量账本、录音状态与句子列表同步更新。

## 模块划分

- `src/storage/ledger.ts` —— 保管账本：登记模型、容量计算、日期工具与持久化
- `src/storage/cleanup.ts` —— 清理判定：资格规则、候选锁定、整批阻止、原子提交（纯函数）
- `src/components/StorageBar.tsx` / `CleanupConsole.tsx` —— 页面控件
- `src/App.tsx` —— 组合三层并保持单一事实来源
